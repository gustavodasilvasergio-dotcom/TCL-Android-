# BeyondTV Clean Launcher

Launcher leve, original e personalizável para **Android TV 9+ (SEMP TCL BeyondTV)**.

## Como compilar no celular (GitHub Actions)
1. Crie um repositório no GitHub (pelo navegador do celular).
2. Envie todos os arquivos deste pacote mantendo a estrutura de pastas (incluindo `.github/workflows/build.yml`).
3. Acesse a aba **Actions** do repositório, selecione o workflow **Build Android TV Launcher APK** (ou aguarde o término automático) e baixe o artefato `beyondtv-clean-launcher-debug` (`app-debug.apk`).
4. Instale o APK na TV via **Bugjaeger** ou **atvTools**.
